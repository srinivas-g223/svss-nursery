# SVSS Nursery website redesign

## Goal
Rebuild the SVSS Nursery website using the polished, conversion-focused structure and green visual language of the Chavans reference, while keeping SVSS Nursery’s own brand, plant imagery, business details, and content.

## Build
- Create a responsive one-page nursery website at `/` with a slim contact strip, sticky navigation, immersive plant hero, plant categories, nursery story, featured plants, benefits, business statistics, gallery, visit/contact section, and footer.
- Use SVSS Nursery’s real public photos, phone number, WhatsApp link, address, hours, plant names, and descriptive copy.
- Add clear call and WhatsApp actions throughout, including mobile floating contact controls.
- Match the reference’s premium deep-green styling, serif display headings, soft green surfaces, bold pills, spacious sections, rounded imagery, and restrained motion.
- Keep navigation within the single finished page because the source site’s linked internal pages currently return 404.

## Technical details
- Define all colors, typography, shadows, and motion as semantic design tokens in the global stylesheet.
- Build reusable in-page sections and use the existing button component for interactive controls.
- Store copied source photography through the project asset workflow rather than hotlinking.
- Add unique home-page metadata and replace placeholder root metadata.
- Verify desktop and mobile layouts, working contact actions, page anchors, and current preview build.
